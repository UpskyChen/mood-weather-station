# 心情天氣站（輔導工具箱草案 v0.2）

原創情緒教育小網站，給輔導室、諮商室和班級輔導課使用。

- 網站：https://upskychen.github.io/mood-weather-station/
- 遊戲：認識情緒卡、情緒偵探、情境配對、心情溫度計、心情冷靜角
- 「需要幫助時」流程（草案，待輔導老師修正）、列印版、老師設定與審稿表
- 角色：松鼠跳跳、烏龜慢慢、穿山甲阿甲、臺灣黑熊圓圓（程式畫的表情臉，每隻都有全部表情）
- 不登入、不上傳、不留紀錄；工具不會自動通知任何人

## 狀態
所有情緒詞、情境、因應方法、求助文字皆為原創草擬，**待輔導老師逐項審定**。
文字集中在 `index.html` 最上方的 `DATA` 區塊，改文字不用動程式。

## 老師設定頁怎麼進去
首頁長按頁尾「心情天氣站 草案…」約 2 秒，或網址加 `#teacher`，再輸入密碼。
密碼在 `index.html` 的 `DATA.teacher.pin`（預設 `2580`），請學校自己改。這只是防止學生誤觸，不是資安保護。

## 直接開某個遊戲
`#cards` `#detective` `#match` `#thermo` `#calm` `#help` `#print`
